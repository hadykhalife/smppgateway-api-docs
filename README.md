# SMPP Gateway — Message API reference

Public reference for applications that send SMS through the SMPP Gateway Management Platform.

- Read it: https://hadykhalife.github.io/smppgateway-api-docs/
- OpenAPI description: [`messages-api.openapi.yaml`](messages-api.openapi.yaml)

Ask your platform operator for the platform address and an API key. This repository holds only the public API
reference; it is published from the platform's `docs/api/messages-api.openapi.yaml`.
